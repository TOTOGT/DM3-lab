# DM3-lab

Source of the DM3-lab web page (`index.html`, one self-contained file, no build step).
Served with GitHub Pages: Settings, Pages, branch `main`, folder `/ (root)`.

Not in this repository: Lean sources and papers. They live in TOTOGT/io and TOTOGT/geometry, and the page links there.
Check the page with `python3 check_site.py` (needs sibling clones of io and geometry for the source checks; it says so when they are missing).
