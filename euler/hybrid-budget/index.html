Conditional hybrid budget

Status: conditional, not a Lean proof, and the conjecture is not proved. Exact-rational arithmetic (Python Fraction) shows that, if a uniform spectral bound (H) holds for every prime p ≤ P(n) = ⌊2n(1−β)/2⌋, the aggregate inequality needed by Sufficiency.sufficiency holds for all n ≥ n0. For β = 1/2, n0 = 644 (this is the existing H31gt3 hypothesis). For β = 0.55, n0 = 1011, which would also need a separate finite check of the interval (644, 1011]. Hypothesis (H) is unproved for every β below 1, and no Lean exists for the moving-cutoff assembly.
